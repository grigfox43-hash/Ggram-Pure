## ⚡ Особенности версии Pure

### 🛡️ 1. 100% Блокировка рекламы (AdBlock)
- Полная вырезка спонсорских сообщений в публичных каналах Telegram.
- Эвристический фильтр рекламных постов (метки `#реклама`, `erid`, `#ad`, инвайт-боты).
- Отключение всплывающих окон покупки Telegram Premium и звезд.

### 🌐 2. Встроенный переводчик сообщений (1-Tap Translate)
- Нажмите кнопку **«🌐 Перевести»** прямо под любым входящим сообщением.
- Мгновенный перевод на русский язык с автоматическим определением языка оригинала.
- Кнопка **«✖ Скрыть перевод»** для возврата к оригинальному тексту.

### 🎨 3. Фирменный стиль и кастомная иконка
- **Иконка:** Однотонная буква **G** фирменного цвета `#01ba53`, выполненная элегантным шрифтом **Playfair Bold** на контрастном глубоком черном фоне `#050505`.
- **Интерфейс:** Полное погружение в темную эстетику `#050505`, карточки `#121814` и изумрудные пузыри сообщений `#0e381f`.

## 🛠️ Сборка
```bash
git clone https://github.com/grigfox43-hash/Ggram-Pure.git
cd Ggram-Pure
./gradlew assembleDebug
```
Готовый APK автоматически собирается при каждом коммите в GitHub Actions.
